# Photo references for 3D models

Drop real photos here so Claude can match the real building.
One folder per place. Use lowercase words joined by dashes.

## How to add a new place
1. Copy the `_template` folder.
2. Rename the copy, for example `fenway-park`.
3. Drag your photos into it.
4. Fill in `notes.md` (2 minutes, short answers are fine).
5. Tell Claude: "Build fenway-park using the photos in references."

## Best photos to grab (in this order)
1. Straight down from above (Google Maps satellite view screenshot).
2. A high angle from each side (aerial or drone shots).
3. Street level: the main entrance and the outside walls.
4. Inside: the seating bowl from the top row.
5. Close-ups of things that make it famous (signs, roof, scoreboard).

## Naming photos
Start the name with what it shows: `top-down.jpg`, `aerial-north.jpg`,
`entrance.jpg`, `inside-bowl.jpg`, `detail-roof.jpg`.

## A note on rights
These photos are for reference only. Claude looks at them to shape the model.
Do not post someone else's photo in a video unless you have the right to.
